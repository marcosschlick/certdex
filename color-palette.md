# Color Palette

## Base colors

- Background: `#282828`
- Text: `#f8f8f8`

## Accent colors

Use accent colors in this priority order:

1. Blue: `#327de1`
2. Red: `#df2935`
3. Purple: `#430671`

Use the dark background and off-white text as the default interface colors.

Accent colors should be used only for highlights, actions, states and important visual elements.

Keep the interface simple and consistent.
